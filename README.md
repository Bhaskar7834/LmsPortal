AEIS LMS Portal

A simple and clean MERN Stack Learning Management System with Admin and Student features.

🚀 Features

Admin can add courses and lessons

Students can watch videos and access materials

JWT authentication

MongoDB database

React frontend + Node.js backend

📦 How to Run
1️⃣ Clone the project
git clone https://github.com/Bhaskar7834/LmsPortal.git

2️⃣ Backend Setup
cd backend
npm install
npm run dev


Create a .env file in backend:

MONGO_URI=your_mongo_url
JWT_SECRET=your_secret
CLOUDINARY_NAME=name
CLOUDINARY_API_KEY=key
CLOUDINARY_API_SECRET=secret
PORT=4000

3️⃣ Frontend Setup
cd ../frontend
npm install
npm run dev
